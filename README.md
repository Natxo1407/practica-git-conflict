## Descripció
Esta práctica tiene como objectivo aprende el flujo de trabajo básico con Git. Durante el ejercicio se realizara lo siguiente:
* Creación y clonaje de repositorios.
* Gestión de ramas (feature branches).
* Creación de Pull Requests.
* Resolución de conflictos de fusión (Merge conflicts).
