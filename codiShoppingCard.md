# ¿Qué es un Pull Request (PR)?
Una Pull Request es un mecanismo que permite a los desarrolladores notificar a los miembros del equipo que han completado una funcionalidad.

## ¿Para qué sirve?
Sirve para revisar el codigom, discutir cambios y finalmente fusionar (merge) el codigo a la rama principal.

## Ventajas:
* Mejorar la calidad del codigo (Code Review).
* Evita errores a la producción.
* Documenta el historial de cambios.
